# Helper: build the attribution header of a vendored file

Helper: build the attribution header of a vendored file

## Usage

``` r
vendor_header_lines(
  repo,
  repo_url,
  author_str,
  license,
  owner,
  files = character(0L),
  desc_vendor = NULL,
  comment = "#",
  imports = NULL,
  nocov = FALSE
)
```
